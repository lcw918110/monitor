管理 Token

加载中…

这是中心写操作的一把共享口令，不是登录账号，也不是 Agent 上报用的 token。上报仍只校验 POST /api/v1/metrics。

未设置时，部署、改主机、生成报告、保存设置都和现在一样不校验。请在中心能被别人访问之前先在这里设上。设上之后，这些写操作都要带当前 Token；清空也要带。读监测数据不需要。更换或清空时，先在页面上方黄条填入当前 Token，再点「本页使用」。

保存后只留哈希，页面不再显示明文。忘记时，在中心机执行 sqlite3 data/monitor.db "DELETE FROM admin_settings WHERE key='management_token_sha256';"，然后立刻重新设置。也可以在首次启动前用环境变量 MONITOR_MANAGEMENT_TOKEN 写入（已有 Token 时不会覆盖）。

诊断报告推送

加载中…

定时生成和页面上的「生成并保存」成功后，会把报告正文发到下面的机器人。未启用或没有 Webhook 时不发请求，报告仍照常入库。

正文过长会截断，并提示到监测台「使用诊断」看全文。钉钉若开了加签，当前版本不会计算签名，请改用自定义关键词，关键词包含「诊断」。

管理 Token 与 Agent 上报 Token 分开。推送未配置时，诊断报告只留在本机。
