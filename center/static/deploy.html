给机器装上采集

  1. 确认「中心地址」是别的机器能访问的地址，不要填 127.0.0.1。
  2. 把机器加进下面的清单，或用表格一次导入。导入只改清单，不会马上安装。
  3. 勾选后点「部署勾选」。部署会在对方机器安装或覆盖采集端，点之前会再确认。

采集端默认装在 /opt/monitor-agent，中心仍在 /opt/monitor。密码登录需要这台中心机已安装 sshpass，也可以改用密钥。清单里的「删除」只去掉这一行，不会卸载已经装好的采集端。

加入一台机器

改一台已有机器时，可以改 IP 和 host_id。另一台已经占用这个 IP 时会拒绝保存。密码留空不会清掉已经保存的密码。停用只是不再参与部署，密码还在。同一台机器换 IP，请到监测台主机详情里用「更换 IP」。

对方没有 Python 3.6 或更新版本时，中心会带上便携解释器。失败时看清单里的短码，下面有人话说明。

用表格一次加入

下载表格模板 表头含 ip、ssh_port、ssh_user、ssh_password、ssh_key_path。端口不填就是 22。导入前会再确认，确认后只写入清单。

不常改的连接

中心地址和默认登录方式设好后很少再动。单台机器可以在左边覆盖。

补跑脚本 中心地址是采集端回传数据用的。密码方式要在这台中心机安装 sshpass，或改用密钥。不要从自己的笔记本另拷一份安装包。

补跑脚本只在清单部署已经把代码同步过去之后，到那台机器上再跑一次。它不是另一条安装办法。

唯一部署方式：本页 SSH 部署，或在中心机跑 deploy_fleet.sh / deploy_agent.sh。密码登录需中心机已装 sshpass（否则短码 sshpass_missing），或改用密钥。非 root 写 /opt 会 sudo。Agent 默认 /opt/monitor-agent。SSH 端口默认 22（不扫端口）。失败消息带短码。
