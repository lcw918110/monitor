# 同类软件对比与差距分析

| 文档版本 | 1.0 |
| 编制日期 | 2026-07-27（自主迭代） |
| 约束 | 不引入 Prometheus/Grafana/Zabbix/DCGM 等外部监控软件 |

---

## 1. 对标对象

| 产品/组合 | 定位 | 典型部署成本 |
| --- | --- | --- |
| Prometheus + Grafana + node_exporter + DCGM-Exporter | 云原生可观测标准栈 | 高（组件多） |
| Zabbix | 企业级统一监控 | 中高 |
| Netdata | 实时本机/集群可视化 | 中（Agent 重） |
| NVIDIA DCGM | 数据中心 GPU 深度遥测 | 中（需驱动生态） |
| Glances / psutil 脚本 | 轻量本机查看 | 低 |
| **本系统 Monitor** | 自研中心汇聚 + 轻量 Agent | **极低（标准库）** |

## 3. 产品定位结论

本系统**不是**要替代 Prometheus/DCGM 生产栈，而是在约束「不引入外部监控软件、基本语句实现」下，覆盖实验室/小集群的：

1. 多机统一看活  
2. GPU/应用资源快照与统计  
3. 轻量历史与阈值告警  
4. 可复制的中心+Agent 分发  

相对市场缺口中，**可自主补齐**的优先项：网络指标、GPU 进程、历史曲线、页内告警、systemd、导出与演示数据。  
**必须人工介入**的：外部通知凭证、生产 Token/网络策略、是否突破 DCGM 约束做深度 GPU 诊断、高可用架构选型。
